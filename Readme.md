# FinViz Pro

A personal finance analytics platform to track expenses, manage budgets, and gain financial insights.

## 📁 Project Structure

```bash
finviz-pro/
├── backend/ # Flask API (see backend/README.md)
├── frontend/ # React app (see frontend/README.md)
└── README.md
```

## 🚀 Quick Start

### Prerequisites

- Node.js 18+, Python 3.11+, PostgreSQL 15+, Redis 7+

## 📚 Documentation

- [Backend Documentation](/backend/README.md) - API, database, authentication
- [Frontend Documentation](./frontend/README.md) - Components, state management, styling

## 🛠️ Tech Stack

- **Backend**: Flask, PostgreSQL, Redis, JWT
- **Frontend**: React, TypeScript, Tailwind CSS, Recharts
